0一分钟看懂这个系统

它帮你做什么

排班、库存与成本、收货确认、培训签名、每天的清洁与测温任务 —— 全部在一个网页里，手机也能用。

它不做什么

不点单收银、不算工资、不解读 Award、不收 TFN 和银行卡、不和任何政府系统对接。它只记录你自己店里的运营数据。

三种身份

老板看全局、开关功能；经理排班、管库存收货；员工看班次、报可用时间、做任务、签培训。

怎么打开

已经装好的门店，直接在浏览器打开你们的网址即可。自己在电脑上跑一份的话：

python3 -m http.server 8899

然后浏览器打开 http://localhost:8899/index.html。直接双击 index.html 也能用。

装到手机桌面：用手机浏览器打开同一个网址 → 分享 → 「添加到主屏幕」，之后就像一个 App，断网也能先用，来网了自动同步。

5常见问题

怎么换语言？
任意页面右上角的下拉框，或者老板端「设置 → 系统语言」。支持简体中文、繁體中文、English、Tiếng Việt、한국어、ไทย。
店里网络不好，能用吗？
能。数据先写在这台设备上，界面立刻有反应；等网络恢复，排队的改动会自动同步到云端。右上角会显示「云端已连接 / Syncing」。
忘记密码了？
登录页点「Forgot password?」，填账号邮箱，系统发一封重置邮件。密码不保存在本程序里，改密码只在云端账号系统生效。
试用（预览）里的数据是真的吗？
不是。预览只是本机的示例数据，没有云端登录，看不到也改不了任何真实门店的数据。想回到登录页，点顶部橙色条上的「退出预览 →」。
员工看得到别人的工资、证件吗？
系统根本不记工资，也不收 TFN、护照号、银行卡。少数敏感字段只有老板能查看，而且每次查看都会写进「审计日志」。
菜单里少了某个功能？
多半是老板在「设置」里把这个模块对你这个角色关掉了，让老板打开即可。
怎么把数据拿出来？
「设置 → 数据导出」选内容和时间范围，导 CSV 或打印成 PDF；库存页也有单独的「导出 CSV」，排班页有「导出」。
